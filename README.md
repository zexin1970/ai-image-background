# AI Background Remover

AI 图片去背景工具 - 快速移除图片背景

## 功能特性

- 🚀 一键上传，自动去背景
- 📱 支持桌面端和移动端
- 🎨 实时预览对比效果
- 💾 下载透明背景 PNG
- 🔒 图片仅在内存处理，不存储

## 技术栈

- Next.js 15
- TypeScript
- Tailwind CSS
- RemoveBG API

## 快速开始

1. 安装依赖：
```bash
npm install
```

2. 配置环境变量：
```bash
cp .env.example .env
```
在 `.env` 文件中填入你的 RemoveBG API Key

3. 启动开发服务器：
```bash
npm run dev
```

4. 访问 http://localhost:3000

## 部署

推荐部署到 Vercel 或 Cloudflare Pages
