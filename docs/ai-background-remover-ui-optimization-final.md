> **状态**: 设计阶段

---

## 1. 项目概述

### 1.1 产品定位
一款基于AI技术的在线图片背景去除工具，面向个人创作者、电商卖家、设计师等需要快速处理图片的用户群体。

### 1.2 设计目标
- **提升转化率**: 优化定价页和首页的用户体验，降低流失率
- **减少认知负担**: 简化信息层级，让用户快速理解产品价值
- **增强信任感**: 通过视觉设计和内容呈现建立用户信心
- **确保一屏可见**: 核心CTA（支付按钮）必须在首屏完整展示

### 1.3 用户画像
| 用户类型 | 核心需求 | 痛点 |
|---------|---------|------|
| 电商卖家 | 批量处理商品图 | 需要快速、低成本 |
| 内容创作者 | 社交媒体素材 | 需要高质量、无水印 |
| 设计师 | 专业级抠图 | 需要精确边缘处理 |
| 普通用户 | 偶尔使用 | 需要简单易用 |

---

## 2. 设计原则

### 2.1 视觉设计原则
1. **深色优先**: 保持现有的深色主题，突出图片处理效果
2. **绿色强调**: 使用 #00D26A 作为品牌主色，传达"成功、完成"的心理暗示
3. **高对比度**: 确保文字与背景对比度符合WCAG 2.1 AA标准
4. **呼吸感**: 保持适当的留白，避免信息过载

### 2.2 交互设计原则
1. **即时反馈**: 每个操作都有明确的视觉或状态反馈
2. **渐进披露**: 复杂功能分步骤展示，降低学习成本
3. **容错设计**: 错误状态提供明确的解决路径
4. **一屏原则**: 核心转化元素必须在首屏可见

## 3. 页面优化设计

## 3.1 定价页 (Pricing Page)

### 3.1.1 当前问题诊断

| 问题类型 | 具体表现 | 影响 |
|---------|---------|------|
| 垂直空间浪费 | 标题过大、警告条独立占据一行、错误提示大面积红色块 | CTA按钮被挤出首屏 |
| 视觉干扰 | 橙色警告条与绿色主题冲突 | 用户焦虑感增加 |
| 信息重复 | "from $2.9"与下方具体选项重复 | 认知负担 |
| 布局松散 | 卡片内边距过大，特性列表间距宽 | 空间利用率低 |

### 3.1.2 优化方案

#### A. 垂直空间压缩

**标题区域优化:**
- 主标题字号从 3rem 缩减至 2rem
- 副标题"Simple pricing. No hidden fees."与主标题同行显示
- 减少标题区域底部间距 60%

**警告条优化:**
- 位置: 改为右上角浮动toast，不占主内容区
- 样式: 缩小为图标 + 简短文字，点击展开详情
- 颜色: 改用品牌色系的柔和警告色

**错误提示优化:**
- 位置: 移至卡片内部底部，按需显示
- 样式: 从大面积红色块改为行内文字提示
- 交互: 提供"重试"按钮，而非仅显示错误

## 4. 视觉设计规范

### 4.1 色彩系统

```css
:root {
  /* 背景色 */
  --bg-primary: #0D1117;      /* 主背景 */
  --bg-secondary: #161B22;    /* 卡片背景 */
  --bg-tertiary: #21262D;     /* 悬停/选中背景 */
  
  /* 品牌色 */
  --brand-primary: #00D26A;   /* 主品牌色 */
  --brand-light: #3EE992;     /* 高亮 */
  --brand-dark: #00A854;      /* 深色变体 */
  
  /* 文字色 */
  --text-primary: #FFFFFF;    /* 主文字 */
  --text-secondary: #8B949E;  /* 次要文字 */
  --text-muted: #6E7681;      /* 辅助文字 */
  
  /* 状态色 */
  --error: #FF6B6B;           /* 错误 */
  --error-bg: rgba(255, 107, 107, 0.1);
  --warning: #F59E0B;         /* 警告 */
  --success: #00D26A;         /* 成功 */
  
  /* 边框 */
  --border-default: #30363D;
  --border-active: #00D26A;
}
```

| 元素 | 字号 | 字重 | 行高 |

| 区块标题 H2 | 1.5rem (24px) | 600 | 1.3 |
| 卡片标题 H3 | 1.25rem (20px) | 600 | 1.4 |
| 正文 | 1rem (16px) | 400 | 1.6 |
| 辅助文字 | 0.875rem (14px) | 400 | 1.5 |
| 小字 | 0.75rem (12px) | 400 | 1.4 |

## 8. 动画与过渡

### 8.1 时间函数

```css
--ease-default: cubic-bezier(0.4, 0, 0.2, 1);
--ease-in: cubic-bezier(0.4, 0, 1, 1);
--ease-out: cubic-bezier(0, 0, 0.2, 1);
--ease-bounce: cubic-bezier(0.68, -0.55, 0.265, 1.55);
```

### 8.2 动画时长

| 类型 | 时长 | 用途 |
|-----|------|------|
| 即时 | 100ms | 按钮按下、颜色切换 |
| 快速 | 200ms | 悬停状态、小元素过渡 |
| 正常 | 300ms | 卡片悬停、页面切换 |
| 慢速 | 500ms | 模态框、大型元素 |

### 8.3 关键动画

**卡片悬停:**
```css
transition: transform 300ms var(--ease-out),
            box-shadow 300ms var(--ease-out);
transform: translateY(-4px);
box-shadow: var(--shadow-card-hover);
```
